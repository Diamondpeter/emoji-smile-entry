One emoji, the one most likely to make a stranger smile: the hugging face 🤗. A hug is the plainest gesture that aims to warm a stranger — it reads instantly, needs no context, carries no irony, and is a friendly offer rather than affection, so it is right coming from someone unknown. One character, four bytes: the smallest possible entry.

## Run it

```sh
python3 main.py
```
